Draft decisions & sources

This is a review adaptation of Marshall et al. (2022), Study 1, using all three existing Find the Caregiver pairing sets. Each assigned set has six stories; the combined 18-story view is for review. Colors and character positions follow one existing balanced visual plan. The orange mom–sister story keeps mom on the left. Every story uses sadness, two helpers, and a plain background. Original study files are unchanged.

Each story asks three main questions: “Who do you think will help…?”, “Who do you think HAS TO help…?”, and “Who was meaner for NOT helping…?” Children choose between the two helpers. There are 18 main judgments in a six-story session, plus introductions, comprehension checks and brief practice. Individual Yes/No ratings and strength scales are omitted.

Adaptation: Marshall Study 1 asked individual prediction and obligation questions. This version measures relative helper choice. Choosing one helper does not establish that the other helper has no obligation. All stories continue with the same explicit outcome: no one helps.

Review choices: stories use a fixed review order; the two choices follow the helpers’ left and right positions in the scene. The brief HAVE TO practice runs once by default; the review control also allows repetition in every story. Checks offer a reminder and allow a retry or facilitator continuation. This private preview does not implement research exclusion rules.

NaturalReader recording script · Recording index

Use Play narration to hear the NaturalReader recording. After starting, the checked automatic-reading option reads each new screen. Stop audio or turn off automatic reading to review manually. On response screens, Read choices uses the recorded NaturalReader voice: each option gains a blue glow as it is spoken, and choices unlock after both. On the three main questions, the matching character glows with its option. Read myself lets the facilitator advance each glow manually. Each option is a separate recording, so the glow follows the spoken choice. Missing recordings are labeled explicitly; there is no automatic substitute voice. Answers remain in memory during researcher review. When embedded in the CHS draft, answer records are passed to the parent review frame; this draft does not start a camera, collect consent, or submit participant responses.
