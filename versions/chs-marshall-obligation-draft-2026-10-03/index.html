Draft decisions & sources

This is a review adaptation of Marshall et al. (2022), Study 1, using all three existing Find the Caregiver pairing sets. Each assigned set has six stories; the combined 18-story view is for review. Colors and character positions follow one existing balanced visual plan. The orange mom–sister story keeps mom on the left. Every story uses sadness, two helpers, and a plain background. Original study files are unchanged.

Predictions and obligations are asked independently for each helper. The story always continues with neither helping. There are eight substantive judgments per story (48 in a six-story session), plus identity and recall checks, practice, and conditional strength questions. The original Find the Caregiver trait/Likert section is omitted.

One item uses proposed wording: the overall “How mean was the thing that happened?” follow-up and its response options. The official supplement confirms an overall intensity measure and score levels, but the exact spoken prompt and responses were not recovered. It is flagged wherever shown.

Review choices: stories use a fixed order and helpers are asked from left to right for review; the published obligation order was randomized. Practice repeats in every story by default, as in the captured Marshall sequence. The optional first-story-only setting is a new adaptation. Practice strength follow-ups are shown after Yes; original practice routing remains unverified. Checks offer a reminder and allow a retry or facilitator continuation; this preview does not implement research exclusion rules.

NaturalReader recording script · Recording index

Use Play narration to hear the NaturalReader recording. After starting, the checked automatic-reading option reads each new screen. Stop audio or turn off automatic reading to review manually. On three-option strength questions, Read choices uses the recorded NaturalReader voice: each option gains a blue glow as it is spoken, and choices unlock after all three. Read myself lets the facilitator advance each glow manually. Each option is a separate recording, so the glow follows the spoken choice. Missing recordings are labeled explicitly; there is no automatic substitute voice. Answers remain in memory during researcher review. When embedded in the CHS draft, answer records are passed to the parent review frame; this draft does not start a camera, collect consent, or submit participant responses.
